AGPL-3.0 오픈소스

테스트를 체계적으로
관리하는 가장 빠른 방법

YM TestCase는 QA 팀과 개발팀을 위한 테스트케이스 관리 도구입니다. 스프레드시트처럼 TC를 작성하고, 자동화 결과를 바로 올리고, 대시보드와 리포트로 진행률과 퇴보를 확인합니다. 기획부터 개발, 배포, 운영까지 혼자 맡았고 실제 QA 업무에 도입해 운영 중입니다.

Why

왜 만들었는가

기존 도구들의 한계를 직접 경험하고, 진짜 필요한 것만 담았습니다.

기존의 문제

  • TestRail - 높은 라이선스 비용, SaaS 종속
  • Excel - 협업 불가, 버전 관리 지옥
  • Kiwi TCMS - 설치 복잡, 느린 UI
  • 자체 개발 - 수개월의 개발 기간

YM TestCase의 해결

  • 무료 오픈소스 (AGPL-3.0)
  • 스프레드시트 스타일 즉시 편집
  • 자동화 결과 가져오기와 CI 업로드로 수동 기록 제거
  • 셀프 호스팅 또는 Vercel + Supabase 배포, 데이터는 직접 보관
Features

핵심 기능

테스트케이스 작성부터 실행, 분석, 리포트까지 - 전체 QA 워크플로우를 하나의 도구에서.

📋

스프레드시트 편집

AG Grid 인라인 편집. 멀티 행 추가, 벌크 삭제, Undo/Redo, 찾기·바꾸기(정규식), TC ID 자동 채우기, 일괄 변경. 같은 칸을 두 사람이 고치면 나중 저장이 덮어쓰지 않고 알림.

🗂️

시트 트리 구조

N-depth 계층형 시트로 테스트 스위트를 폴더처럼 관리. 그 자리에서 이름 변경, TC를 포함한 시트 복사.

⚙️

커스텀 필드 · 필드 설정

6가지 필드 타입(텍스트, 숫자, 셀렉트, 멀티셀렉트, 체크박스, 날짜). 기본 필드 표시 이름 변경과 숨김을 프로젝트별로 관리.

🧪

테스트 수행

시트를 골라 수행 생성. P/F/B/N 단축키, 범위 채우기, 첨부파일. 결과 저장은 낙관적 잠금으로 보호하고, 완료된 수행은 TC 내용을 그 시점으로 고정.

🏠

메인 화면 현황

진행 중 수행과 최근 완료 수행 기준으로 프로젝트별 진행률·합격률 요약. 프로젝트 순서를 끌어 놓아 사용자별로 저장.

📊

대시보드

버전·수행·기간별 결과 분포, 회차별 비교, 추이와 히트맵. 회차 사이에 결과가 바뀐 TC를 찾는 TC 안정성 표.

📄

리포트

웹·PDF·엑셀. 우선순위별·분류별 PASS Rate, 직전 회차 대비 수정·미수정·퇴보 TC, 실패·차단 항목과 이슈 종합.

🤖

자동화 결과 가져오기

Playwright JSON·JUnit XML 결과를 미리보기 후 테스트 수행에 기록. CI 업로드 CLI는 수행 이름만으로 다음 회차를 만들어 올림.

🔑

API 키

스크립트·CI용 사용자별 키. Bearer 인증, 범위 지정, 발급·폐기. 사용 중지한 계정의 키는 바로 차단.

🔍

고급 필터

AND/OR 다중 조건 필터. 6가지 연산자(=, !=, 포함, 미포함, >, <). 필터 저장·불러오기.

📥

Import / Export

Excel 멀티시트·Jira CSV(헤더 매핑, CP949/UTF-8 BOM 자동 감지)·Markdown 가져오기. Excel·PDF·Markdown 내보내기.

🎯

테스트 플랜

마일스톤 기반 테스트 계획. 릴리즈별 수행 추적과 진행률.

🔗

이슈 관리 도구 연동

Jira·Linear 주소를 설정하면 이슈 키가 수행 시트와 리포트에서 링크로 열림.

🔐

인증 & 권한

Google Workspace 로그인과 가입 승인, 아이디 계정 병행. 시스템 역할과 프로젝트 역할의 이중 RBAC. 아이디 찾기·비밀번호 재설정.

🛡️

보안

httpOnly 쿠키, CSRF 보호, DB 기반 Rate Limiting, bcrypt. 업로드 크기·압축 해제 상한. 운영 도입 전 보안 점검과 패치.

🌐

다국어 지원 (i18n)

한/영 완전 지원. 언어당 15개 로케일 파일, 2,091개 번역 키. AG Grid 로케일 자동 전환.

♿

접근성 (a11y)

ARIA role·키보드 조작(목록 순서 변경 포함), E2E에서 axe 접근성 검사, 다크 테마 WCAG AA 명암비.

📝

개발 이력 관리

102회 릴리즈를 버전 규칙(System·BE·FE·DB 축 분리), 릴리즈 노트, 이슈 로그와 트래커 1:1 연결로 관리.
